# MAP — 從問題到工具

> 這份文件是整本書的「鳥瞰圖」。
>
> **目標**:讓你在翻開任何一章前,先看清楚:
> 1. 我們**反方向**走——從**問題**出發,而不是從工具出發。
> 2. 整本書只有**5 類問題**(Q1–Q5)。
> 3. 解 5 類問題只需要 **12 個底層數學工具**——其中**少數幾個工具被反覆使用**。
> 4. 我們選的**例題全是真實場景**,不是課本捏造的。

---

## §1 本書的方向:**反**傳統教科書

### 傳統路線(由下往上)

```
微積分 → ODE 理論 → 線性代數 → 動力系統 → 偏微分 → ...
   ↓        ↓           ↓           ↓          ↓
                    [滿屋子工具]
                         ↓
              「**找個應用題練練吧**」
```

**問題**:當你終於到「應用」那一站,**你已經不記得為什麼要學這些**。每個工具都教過,但**沒有任何一個被用得特別深、特別熟**。讀者結業後會建模嗎?常常不會。

### 本書路線(由上往下)

```
            **真實生物問題**
                 ↓
       「我**到底**要回答什麼?」
                 ↓
        歸類成 5 類問題之一(Q1–Q5)
                 ↓
       「這類問題該用什麼工具?」
                 ↓
         展開 2–3 個底層工具
                 ↓
       建模 → 分析 → 回答原問題
```

**好處**:
- 工具是**為了某個具體問題**才學——記得住、用得出。
- **同一個工具會在不同 Q 出現**——重複使用會強化記憶。
- 每讀完一章,**你能多解一類問題**,而不是「**多認識一個工具**」。

> 圖見 `figures/MAP/fig1_directions.png`(兩種路線的對照)。

## §2 上層 Map:**5 類問題** (Q1–Q5)

任何生物模型分析問題,**都會落在以下 5 類之一**(或多個的組合)。

| Q | 問題 | 一句話形式 | 真實場景例子 |
|---|---|---|---|
| **Q1** | 穩定還是失控? | 「擾動會放大還是消退?」 | 流行病會自熄還是失控?物種引入會殖民還是滅絕? |
| **Q2** | 長期會去哪? | 「平衡點 / 吸引子在哪?」 | 藥物穩態血中濃度多少?流行最終感染多少人? |
| **Q3** | 走得多快? | 「特徵時間 / 半衰期是多少?」 | 鎮定劑多久代謝完?神經元多快回到靜息? |
| **Q4** | 對擾動敏感嗎? | 「參數小變動,結果會質變嗎?」 | 漁業捕撈量超過 X 會崩盤嗎?疫苗覆蓋率低 5% 會怎樣? |
| **Q5** | 從資料反推? | 「用觀測時序估計參數 / 結構」 | 早期 case count 反推 R₀;PK 曲線估清除率 |

對應的**深挖章節**在 [Ch 03](03-Q1-穩定還是失控.md)–[Ch 07](07-Q5-從資料反推.md)——一章一個 Q。

## §3 下層 Map:**12 個底層數學工具**

把所有 Q 加起來,需要的數學工具是這 12 個:

### A. 模型「**結構**」工具(寫 ODE 用)

| # | 工具 | 一句話 | 第一次出現 |
|---|---|---|---|
| T1 | **per capita 速率** | $\dot N = a N$ — 常數比例 | Ch 04 |
| T2 | **質量作用律** | $\dot N = a N M$ — 兩族群相遇 | Ch 03 |
| T3 | **logistic / 飽和形式** | $\dot N = r N(1 - N/K)$ | Ch 03, 06 |
| T4 | **守恆律** | 多個 ODE 加起來 = 常數 | Ch 04 |
| T5 | **多時間尺度 / 慢流形** | 快變數先平衡、慢變數主導長期 | Ch 05 |

### B. 模型「**行為**」工具(分析用)

| # | 工具 | 一句話 | 第一次出現 |
|---|---|---|---|
| T6 | **平衡點 + 線性化** | 設 $\dot x = 0$ 解 $x^\ast$;Taylor 展開到一階 | Ch 03 |
| T7 | **Jacobian 與特徵值** | 2D+ 系統的「斜率」是矩陣;特徵值號數 = 穩定性 | Ch 03 |
| T8 | **Phase plane / nullclines** | 2D 系統的「相空間」幾何;nullclines 交點 = 平衡 | Ch 04 |
| T9 | **Bifurcation** | 參數變動使穩定性翻轉的「定性轉折」 | Ch 06 |
| T10 | **敏感度分析** | $\partial(\text{結果}) / \partial(\text{參數})$ | Ch 06 |

### C. 模型「**接資料 + 算 + 確認**」工具

| # | 工具 | 一句話 | 第一次出現 |
|---|---|---|---|
| T11 | **數值積分** | Euler / RK / `solve_ivp` 把 ODE 算出來 | Ch 03 |
| T12 | **參數擬合** | 最小平方 / Levenberg-Marquardt 從資料反推 | Ch 07 |

(隨機建模、PDE 等更高階工具留到後續延伸,不在本書主軸。)

| **T12** 擬合 | | | | | ★★ |

(★ = 用到;★★ = 該 Q 的「核心」工具)

### 觀察 1:**T11(數值積分)貫穿所有 Q**

→ 學它的回報率最高。**不會數值積分,你連模型都驗不了**。

### 觀察 2:**T6 + T7(線性化 + 特徵值)幾乎貫穿前 4 個 Q**

→ 這是最大的「**force multiplier**」。學完一次能解 Q1、Q3、Q4 的核心。Q2 的多平衡點分析也常從特徵值看穩定性。

### 觀察 3:**T8(Phase plane)是 Q2/Q3/Q4 的視覺主軸**

→ 跨章節重複出現。**畫出 phase plane 的能力 = 看見模型在做什麼的能力**。

### 觀察 4:**T2 / T3(質量作用 / logistic)是「結構」的基本款**

→ 90% 的 ODE 模型是這兩個 + per capita 的組合。**識別這幾個 pattern 就能讀懂大部分文獻模型**。

### 觀察 5:**T12(擬合)只用在 Q5**

→ 但 Q5 的應用幾乎涵蓋所有實驗工作,所以**T12 的 ROI 高、但是「最後一哩」**——前 4 個 Q 答對,T12 才有意義。

## §5 「Force multipliers」:該優先學哪些工具?

按**「服務多少 Q」**排:

| 排名 | 工具 | 服務的 Q | 學習回報率 |
|---|---|---|---|
| 🥇 | **T11 數值積分** | Q1, Q2, Q3, Q4, Q5 (5 / 5) | 最高 |
| 🥈 | **T6+T7 線性化 + 特徵值** | Q1, Q2, Q3, Q4 (4 / 5) | 極高 |
| 🥉 | **T8 Phase plane** | Q2, Q3, Q4(+Q1 的 2D 情境) | 極高 |
| 4 | **T3 logistic / 飽和** | Q1, Q2, Q4 | 高 |
| 5 | **T2 質量作用** | Q1, Q2 | 中 |
| 6 | **T9 Bifurcation** | Q1, Q4 | 中 |
| 7 | T1, T4, T5, T10, T12 | 各服務 1–2 個 Q | 場景特定 |

> 圖見 `figures/MAP/fig3_force_multipliers.png`(視覺化工具回報率)。

**這就是為什麼本書的順序是 Ch03 → Ch04 → Ch05 → Ch06 → Ch07**:每一章帶你掌握 1–2 個工具,而**前面章學的工具會在後面章繼續用**——線性化在 Ch03 學、Ch04/05/06 都繼續用。**沒有「學完就丟」的工具**。

## §7 跟其他資料的關係

本 repo 裡還有兩份「平行宇宙」的教材,定位不同:

- **`redesigned/`**:**傳統「方法先」**的 10 章講義(原 NTU 課程結構)。當作**參考手冊**——當你卡在某個工具的細節時去翻。
- **`example-questions/`**:期中考題的**詳細解答**。**很多 case 與本書應用例題重疊**,可以雙向參照。
- **`extracted/`**:從原 PDF 抽取的純文字。**source of truth**。

> **本書(`problem-first/`)的角色**:把 `redesigned/` 的工具與 `example-questions/` 的真實題目,**用「問題 → 工具」的方向重新串起來**。

## §8 怎麼用這份 Map

### 用法 1:**讀章節時的定位**

每讀一章,問自己:
- 這章在解 Q? 中的哪個?
- 用到 12 個工具裡的哪幾個?
- 跟前面章學過的工具重疊嗎?

→ 若答得出來,你就「**懂了**」。若答不出來,**回頭翻這份 MAP**。

### 用法 2:**遇到新問題時的拆解**

看到陌生的生物模型或論文,問:
- 作者**真正**想回答的問題是什麼?歸到 Q1–Q5 中的哪個?
- 他用了哪些工具(從 12 個裡找)?
- **如果換我,我會挑同樣的工具嗎?**

→ 這是把「會建模」變成「會讀別人建模」的關鍵練習。

### 用法 3:**規劃自己的研究**

當你要動手做一個新模型,問:
- 我要的**主問題**是 Q? 哪一個?
- 直接需要的工具是哪 2–3 個(從 12 個裡選)?
- **我能跳過哪幾個工具?**(誠實面對:不要為了顯得「完整」而堆方法)
